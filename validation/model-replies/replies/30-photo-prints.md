# Choosing print sizes and crops

Print sizes look simple until you realize your camera's frame doesn't match the paper.

## The mismatch

Most cameras shoot a 3:2 frame. Common print sizes are not 3:2:

| Print size | Ratio | Crop needed from 3:2 |
| ---------- | ----- | -------------------- |
| 4" x 6"    | 3:2   | None                 |
| 5" x 7"    | 7:5   | Trim the long side   |
| 8" x 10"   | 5:4   | Trim noticeably      |
| 11" x 14"  | 14:11 | Trim more            |
| 16" x 20"  | 5:4   | Trim noticeably      |

The bigger the difference, the more of the image you lose. If a subject is near the edge of the frame, an 8" x 10" print may cut it off.

## Compose with the crop in mind

If you know you'll print at 8" x 10", leave a bit of extra space on the long sides when you shoot. Most cameras can display a 5:4 grid overlay to help.

## Resolution

For a good print, aim for 240 to 300 pixels per inch at the viewing size. That means:

- 4" x 6": about 1200 x 1800 pixels
- 8" x 10": about 2400 x 3000 pixels
- 16" x 20": about 4800 x 6000 pixels, or less if people will view it from a distance

A 24-megapixel camera, about 6000 x 4000 pixels, comfortably supports a 16" x 20" print with a small crop.

## Framing and mats

A mat makes the visible print smaller. An 8" x 10" print in a frame with a 2" mat on each side needs a 12" x 14" frame. Measure the opening before you buy, not the outer dimensions.

## Paper

- **Glossy** gives punchy color but shows fingerprints and glare.
- **Matte** cuts glare and looks more like a fine-art print.
- **Luster** sits between them and is the usual choice for family portraits.

## Practical steps

1. Choose the print size first.
2. Crop your photo to that ratio in your editing software, so you decide what's cut.
3. Check the pixel dimensions against the table above.
4. Order one small test print before ordering a large one.
