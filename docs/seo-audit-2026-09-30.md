# SEO audit: typograph.dev

**Date:** 2026-09-30
**Scope:** full site (three routes: `/`, `/changelog`, `/specimen`), technical and on-page. No Search Console access; index status inferred from external search.
**Method:** raw HTTP probes with curl (what a crawler sees before JavaScript), the rendered DOM in a browser (what JavaScript adds), a local Lighthouse run in headless Chrome with mobile emulation, and the source in `apps/playground`, `worker/`, and `wrangler.jsonc`.

## Executive summary

The site is technically clean in the ways that are easy to get right (HTTPS, canonical, Open Graph, valid HTML, responsive, no horizontal overflow, fast origin) and weak in the ways that decide whether it gets found at all. It is a client-rendered single-page app: the HTML Google and AI crawlers download contains no text. It is not yet in the search index we checked, has no sitemap, and its richest searchable content (the integration guide and the changelog) is either served as plain text or folded into the homepage by a shared canonical.

**Top priorities**

1. Prerender the three routes to static HTML at build time. This is the single change that fixes indexation, AI-crawler visibility, and most of the mobile speed problem.
2. Add a sitemap and a real robots.txt, then verify the domain in Google Search Console and submit the sitemap.
3. Redirect HTTP to HTTPS and add an HSTS header.
4. Give `/changelog` its own canonical and description so its release notes can rank; decide whether `/specimen` should be indexable.
5. Turn the integration guide into an HTML page. It is the most search-relevant content on the domain and currently ships as `text/plain`.

**Quick wins** (under an hour each): preload the hero serif font, subset Inter, fix the second H1, trim the meta description, add JSON-LD, add GitHub topics.

## Technical findings

### 1. No content in the HTML without JavaScript

- **Impact:** High
- **Evidence:** `curl https://typograph.dev/` returns 2.8 KB with an empty `<body>` apart from `<div id="root">` and one module script. The rendered page has 1,590 words, one H1, six H2s. Google can execute JavaScript but queues rendering separately, and AI crawlers (GPTBot, ClaudeBot, PerplexityBot) largely do not execute it, so they index nothing.
- **Fix:** Prerender at build time and hydrate on load. Playwright is already a dev dependency, so the smallest change is a post-build script that serves `dist/`, visits `/`, `/changelog`, and `/specimen`, and writes the rendered HTML to `dist/index.html`, `dist/changelog/index.html`, `dist/specimen/index.html`. Switch `createRoot` to `hydrateRoot` in `main.tsx`. Alternatives: `vite-react-ssg` or `vite-plugin-prerender`. With per-route files in place, the SPA rewrite in `worker/index.ts` can go.
- **Priority:** 1

### 2. Not indexed, no sitemap, no Search Console

- **Impact:** High
- **Evidence:** `site:typograph.dev` returns zero results in the search index we queried. `/sitemap.xml` is 404. The domain went live in the second half of September 2026, so this is partly age, but nothing is helping discovery.
- **Fix:** Add `apps/playground/public/sitemap.xml` listing `/` and `/changelog` (and `/specimen` only if it becomes indexable, see finding 5). Verify `typograph.dev` in Google Search Console and Bing Webmaster Tools and submit the sitemap. Request indexing of `/` once prerendering ships.
- **Priority:** 1

### 3. HTTP is served, not redirected; no HSTS

- **Impact:** Medium
- **Evidence:** `http://typograph.dev/` returns 200 with the full page instead of redirecting. No `Strict-Transport-Security` header on HTTPS responses. `typograph.ing` correctly 308s to `https://typograph.dev/`.
- **Fix:** Either enable "Always Use HTTPS" in the Cloudflare zone, or add to `worker/index.ts` before the asset fetch: if `url.protocol === 'http:'`, set it to `https:` and return a 301. Add `Strict-Transport-Security: max-age=31536000; includeSubDomains` to the `/*` block in `public/_headers`.
- **Priority:** 2

### 4. robots.txt has no directives

- **Impact:** Medium
- **Evidence:** `/robots.txt` is Cloudflare's injected Content Signals boilerplate (comments only). There is no `User-agent`, `Allow`, or `Sitemap` line, and no file in `public/`.
- **Fix:** Add `apps/playground/public/robots.txt`:

  ```
  User-agent: *
  Allow: /

  Sitemap: https://typograph.dev/sitemap.xml
  ```

  Add explicit AI-crawler lines if you want to state a stance (see the ai-seo skill). Cloudflare may still prepend its content-signal comments; that is harmless.

- **Priority:** 2

### 5. Secondary routes share the homepage canonical and description

- **Impact:** High for `/changelog`, Low for `/specimen`
- **Evidence:** `/changelog` sets its own title ("Changelog — Typograph") in JavaScript but keeps `<link rel="canonical" href="https://typograph.dev/">` and the homepage description. Google will treat it as a duplicate of `/` and drop 1,425 words of release notes. `/specimen` has the homepage title and canonical, and its H1 is a sample sentence.
- **Fix:** With prerendering, emit a per-route `<title>`, `<meta name="description">`, and self-referencing canonical. Suggested changelog description: "Release notes for @calebduren/typograph: every change to rendered output, listed by version." For `/specimen`, either give it a real title and canonical ("Specimen — Typograph") or add `<meta name="robots" content="noindex">` if it is only a design fixture.
- **Priority:** 2

### 6. Mobile speed: LCP 4.7 s, FCP 4.3 s (lab)

- **Impact:** Medium
- **Evidence:** Lighthouse mobile (simulated slow 4G): performance 73, FCP 4.3 s, LCP 4.7 s, CLS 0, TBT 30 ms. Origin TTFB is 40 ms, so this is all front-end. The LCP element is the hero H1 span in Hedvig Letters Serif. Contributing factors: nothing paints until 92 KB of JavaScript runs; the 13 KB stylesheet is render-blocking; the serif font is not preloaded and is discovered late (loads at 249 ms); Inter Variable roman is 352 KB and was downloaded even on a Mac; fonts are cached for one week.
- **Fix, in order of payoff:**
  1. Prerendering (finding 1) lets the browser paint text before JavaScript.
  2. `<link rel="preload" href="/fonts/HedvigLettersSerif.woff2" as="font" type="font/woff2" crossorigin>` in `index.html`.
  3. Subset Inter to Latin. Inter 4.1 ships Latin subsets; expect roughly 100 KB per file instead of 350 to 390 KB. Or add `unicode-range` on the `@font-face`.
  4. Check the `--sans` stack order in `landing.css` line 32. If `'Inter Variable'` precedes `-apple-system`, Apple devices download it needlessly, contradicting the intent in PRODUCT.md.
  5. Change `/fonts/*` cache from `max-age=604800` to `max-age=31536000, immutable`, and rename the file when the font changes.
- **Priority:** 2

### 7. Two H1 elements on the homepage

- **Impact:** Low to Medium
- **Evidence:** H1s are "Your AI writes, typograph polishes" and "Thursday brief". The second comes from `finished-samples.ts`, whose Markdown sample starts with `# Thursday brief` and is rendered as real HTML inside the workbench preview.
- **Fix:** Demote headings inside demo output. A tiny rehype step in the preview pipeline that shifts `h1`→`h3`, `h2`→`h4` keeps the sample honest and the page outline clean. The same applies to the `/specimen` route if it stays indexable.
- **Priority:** 3

### 8. No structured data

- **Impact:** Low to Medium
- **Evidence:** No `application/ld+json` in the static HTML or the rendered DOM.
- **Fix:** Add one JSON-LD block to `index.html` (the CSP does not affect it; JSON-LD is not executed):

  ```json
  {
    "@context": "https://schema.org",
    "@type": "SoftwareSourceCode",
    "name": "Typograph",
    "description": "Careful English typography for AI-generated text: streamed chat, finished Markdown, and plain strings.",
    "url": "https://typograph.dev/",
    "codeRepository": "https://github.com/calebduren/typograph",
    "programmingLanguage": "TypeScript",
    "runtimePlatform": "Node.js 22, modern browsers",
    "license": "https://opensource.org/licenses/MIT",
    "author": {
      "@type": "Person",
      "name": "Caleb Durenberger",
      "url": "https://calebduren.com/"
    }
  }
  ```

  See the schema skill for a WebSite block and validation with the Rich Results Test.

- **Priority:** 3

### 9. www hostnames do not resolve

- **Impact:** Low
- **Evidence:** `www.typograph.dev` and `www.typograph.ing` fail DNS.
- **Fix:** Add DNS records for both and extend the hostname check in `worker/index.ts` to redirect any hostname other than `typograph.dev` to it.
- **Priority:** 4

### 10. Empty 404 responses

- **Impact:** Low
- **Evidence:** Unknown paths return 404 with no body and no content type. Correct status, poor experience.
- **Fix:** Add `public/404.html` and set `assets.not_found_handling` to `"404-page"` in `wrangler.jsonc`.
- **Priority:** 4

## On-page findings

### 11. Meta description is 162 characters

- **Impact:** Low
- **Evidence:** Current: "English-only typography for AI-generated text: streaming chat, finished Markdown, and plain strings. Compare careful punctuation and optional no-break spacing in your browser." Google truncates around 155.
- **Fix:** "Careful English typography for AI-generated text. A small Remark plugin for streaming chat, plus typeset() for finished Markdown, HTML, and plain strings." (151 characters, leads with the keyword, names the entry points.)
- **Priority:** 3

### 12. Title tag

- **Status:** Fine. "Typograph — Better typography for AI-generated text." is 53 characters, keyword-led, unique. Consider dropping the trailing period.

### 13. Heading structure

- **Status:** Good apart from finding 7. H2s describe sections; H3s sit under them. The changelog uses one H1 and version H2s.

### 14. Integration guide served as plain text

- **Impact:** Medium
- **Evidence:** `/integration.md` is 16 KB of exactly the content people search for (AI Elements, shadcn, Streamdown, Cloudflare Agents, generic Remark), delivered with `Content-Type: text/plain` and `Content-Disposition: inline`. Plain text has no title, no headings for the index, no internal links, and no description.
- **Fix:** Render it as an HTML page at `/integration` with its own title ("Integrate Typograph with AI Elements, Streamdown, and Cloudflare Agents"), description, canonical, and H2s per stack. Keep `/integration.md` for agents and link it from the HTML page's head with `<link rel="alternate" type="text/markdown" href="/integration.md">`. Add it to the sitemap.
- **Priority:** 2

### 15. Internal linking

- **Status:** Adequate for three routes. Header links to Changelog and GitHub; footer links npm, Typehug, source, and author. The "View the measurement" link points at a content-hashed JSON asset, which is fine but will break as a bookmark on the next build.

### 16. Images and SVG

- **Status:** Good. No `<img>` elements; all nine inline SVGs are `aria-hidden="true"`. Open Graph images (1200×630 and 1200×1200) exist with alt text and match the current olive-and-lime identity.

## Content and quality findings

### 17. Accessibility contrast failures

- **Impact:** Low for ranking, Medium for users
- **Evidence:** Lighthouse flags `#6f7566` muted text on the dark background at 3.89:1 (nav links, hero subline, pane metadata) and `.stream-label` at 1.7:1. "Copy" buttons carry the aria-label "Copy agent prompt", which mismatches the visible text.
- **Fix:** Lift the muted token to reach 4.5:1 and make the aria-label start with the visible label ("Copy agent prompt" is fine if the visible text becomes "Copy agent prompt", or change it to `aria-label="Copy"` plus `aria-describedby`).
- **Priority:** 3

### 18. E-E-A-T

- **Status:** Reasonable for a developer tool. Author is named and linked, source is public, license is stated, and limits are documented on the page. No customer proof yet, which the marketing context already records.

### 19. Keyword landscape

- **Evidence:** Searching "typograph AI text typography remark plugin" surfaces codsen's `remark-typography`, `@mavrin/remark-typograf`, and `typographic-markdown`. None mentions AI, streaming, or chat. Typograph's own positioning has no competition in search yet.
- **Opportunity:** The integration page (finding 14) and a short "why smart quotes break on streaming text" explainer would own the "streaming markdown typography", "AI chat smart quotes", and "Streamdown plugins" phrases. See content-strategy and ai-seo for follow-up.

### 20. Off-site signals

- **Evidence:** GitHub repo has 0 stars, no topics, and a description ("Typography principles, reading styles, and inspectable punctuation for the web and AI agents.") that does not match the site's positioning. npm keywords are good.
- **Fix:** Set the GitHub description to the one-liner from `.agents/product-marketing.md` and add topics: `remark-plugin`, `typography`, `markdown`, `ai`, `llm`, `streaming`, `smart-quotes`, `typescript`.
- **Priority:** 3

## Things that are fine

HTTPS certificate and CSP, canonical on the homepage, `lang="en"`, viewport, no horizontal overflow at 375 px, CLS 0, origin response 40 ms, hashed assets cached for a year, HTML `must-revalidate`, Open Graph and Twitter cards complete, web manifest present, `typograph.ing` redirect, no hreflang needed (single language by design).

## Status after the same-day fix (deployed 2026-09-30)

All findings except Search Console verification were fixed and deployed in one change. Live checks after deploy:

- `/`, `/changelog`, `/integration`, and `/specimen` are prerendered at build time with React's static renderer and hydrate in the browser with no console output. Raw HTML now carries 1,771 words on the homepage and 2,357 on the integration page.
- Each route has its own title, description, and canonical; `/specimen` is `noindex`. JSON-LD and the serif preload are in the head.
- `robots.txt` and `sitemap.xml` are live; HTTP, `www.*`, and `typograph.ing` all redirect to `https://typograph.dev`; HSTS is set; unknown paths get a styled 404.
- Inter is Latin-subset (352 KB → 132 KB roman, 388 KB → 146 KB italic) and no longer downloads on Apple devices; fonts cache for a year.
- Lighthouse mobile went from performance 73 (FCP 4.3 s, LCP 4.7 s) to 100 (FCP 1.0 s, LCP 1.3 s). SEO and best practices 100, accessibility 97.
- The workbench preview demotes its headings, so the homepage has one H1. Muted-text tokens now clear 4.5:1; the only remaining contrast flag is the stream column label during its scroll-driven fade, which is decorative and `aria-hidden`.
- GitHub description and topics were aligned with the site's positioning.

Still open: verify `typograph.dev` in Google Search Console and Bing Webmaster Tools and submit `https://typograph.dev/sitemap.xml`. This needs the owner's Google account.
